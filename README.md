# Library Management System

A web-based Library Management System developed as a Web Programming Mini Project at German-Malaysian Institute.

## Project Overview

This project aims to simplify library operations through a database-driven web application developed using PHP and MySQL.

## Features

- User Login Authentication
- Book Reservation Management
- Print Service Management
- Study Room Reservation
- Create, Read, Update and Delete (CRUD) Operations
- Search and View Records
- Automatic Printing Cost Calculation

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- phpMyAdmin
- XAMPP

## Database

The project uses MySQL to store user information, book reservations, printing requests and study room reservations.

The SQL database file is available in the `database` folder.

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Clone or download this repository.
4. Place the project folder inside `htdocs`.
5. Open phpMyAdmin.
6. Create and import the project database using the provided SQL file.
7. Configure the database connection.
8. Open `http://localhost/library-management-system/`.

## Project Purpose

This project demonstrates practical skills in PHP programming, database management, SQL queries, authentication and web application development.
